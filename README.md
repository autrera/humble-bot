# Humble Bot

`Humble Bot` is a personal assistant made of plain text files in a folder. There is no background service or account system.

You talk to it. Ask it to remember things and to create the skills you need to improve it. Make it yours.

## Setup

1. Clone this repository. 
2. Run `python bootstrap.py`, or `py -3 bootstrap.py` on Windows. 
3. Edit `data/SOUL.md` to describe the assistant you want(or ask the bot in your first chat to interview you and fill it in).
4. Open the `humble-bot` folder in your coding agent and start a new chat.

## Files

- `AGENTS.md` tells your coding agent to read every file in `data/` when a session starts, and to place any new bot skills in `.agents/skills/`.
- `data/` holds your personal files. Gitignored so any change does not get tracked.
  - `SOUL.md` defines how the assistant behaves and any personal rules. You can rename it or split your notes across multiple files, since the agent loads everything in `data/`.
  - `MEMORY.md` holds working memory exported by `mind.py`. Do not edit this file by hand because `mind.py` overwrites it.
- `mind.py` is an offline memory tool from `Da7-Tech/mind` under the MIT license, modified here to export only to `data/MEMORY.md`. It stores its graph in `.mind/`, which git ignores.
- `bootstrap.py` sets up a fresh clone. It creates a starter `data/SOUL.md` if missing, links `.claude/skills` and `.opencode/skills` to `.agents/skills`, and runs `mind.py init`.
- `.agents/skills/` holds your custom skills. Git ignores everything here, so your personal skills stay local.
- `.claude/skills` and `.opencode/skills` link to `.agents/skills` so Claude Code and OpenCode load the same skills.
- `.gitignore` excludes `data/`, `.mind`, `.agents/skills/`, `.claude/skills/`, and `.opencode/skills/`.
